## Selected projects

### [VMware Community Toolkit](https://github.com/danielfuentespl/vmware-community-toolkit)
A collection of PowerCLI tools for VMware administration and automation, including vSphere reporting, ESXi configuration observations and offline analysis of VMware Cloud Foundation exports.

### OmaOps
A small family of native Omarchy plugins:

- [OmaPiHole Monitor](https://github.com/danielfuentespl/omarchy-pihole-monitor) — read-only Pi-hole v6 status in the Omarchy desktop bar.
- [OmaHomepage](https://github.com/danielfuentespl/omarchy-homepage) — a Quickshell panel for browsing and searching services from Homepage.
